# Production Webapp Toolkit v2.2.0

Status: v2.2.0 minor release

## Status semantics

Toolkit v2 status semantics remain monotone. Deterministic checks, explicit evidence, repository manifests, policy packs, leases and deployment gates remain authoritative over model output. Missing or unverified evidence is never promoted to PASS by an agent conclusion.

The integrations added after v2.1.0 are additive. Existing repository manifests and policy packs continue to resolve without opting into the new capabilities.

## Trust boundaries

v2.2.0 keeps the public toolkit generic and provider-neutral. It contains no maintainer host access, private worker credentials, customer data, application business truth or deployment secrets.

Agent write authority remains task-, role-, lease-, worktree- and policy-bounded. It does not imply merge, deployment, payment, booking, migration or production authority.

Runtime, incident and contract evidence describes observations and correlations. It does not establish causality, runtime authenticity or business correctness unless a separate canonical evidence source establishes that property.

## New capabilities since v2.1.0

### Controlled agent execution

* Official bounded MCP v2 stdio server with a fixed read-only toolkit operation allowlist.
* Task-scoped Bubblewrap/prlimit worktree sandboxing with exact command allowlists and deterministic cleanup.
* Ed25519 signed-evidence verification with signer, key, domain, kind and freshness policy binding.
* Reusable research bundles with exact task/commit, tool-version, SHA256 and sanitized-evidence bindings.
* Repository impact graph for explicit APIs, contracts, canonical modules, tests, routes and consumers.
* Read-only operator task dashboard over canonical task-registry and worker-lease state.

### Runtime and incident intelligence

* Incident-analysis agent with exact release/runtime binding and evidence-cited hypotheses.
* Bounded OpenTelemetry evidence adapter for traces, metrics and logs.
* Deterministic incident correlation across release windows, dependency commits, contract edges and prior failure signatures.
* Agent resource/model-quality telemetry covering latency, CPU/GPU time, token use, proposal outcomes and review effort.
* Model-routing evaluation with conservative small-first routing and measured-quality escalation.

### Advanced verification

* Playwright planner/generator integration with AST auditing and hard rejection of skip/fixme/only/fail constructs.
* fast-check property-based testing adapters with deterministic seed/replay behavior.
* StrykerJS mutation-testing integration with exact source scope and bounded test-only command policy.
* Testcontainers 12.1.0 disposable synthetic service environments with pinned images, dynamic ports and reverse-order cleanup.
* Pact 17.1.4 literal HTTP v3 consumer/provider verification with exact clean-commit and contract-hash binding, loopback-only provider lifecycle, redirect/timeout/output boundaries and native positive/negative smoke coverage.

## Upgrade notes

v2.2.0 is a backwards-compatible minor release for existing v2.1.0 adopters. Projects pinned to v2.1.0 may move the toolkit checkout ref to v2.2.0 without enabling every new capability.

New advanced integrations are opt-in unless a private organization policy or repository manifest explicitly makes their evidence required. Application-specific business rules must remain in private policy or canonical application implementations rather than being inferred by the public toolkit.

Reference verification:

    bun install --frozen-lockfile
    bun run release:verify
    bun run audit:release . --expected-version 2.2.0
    bun run integration:testcontainers:smoke
    bun run integration:pact:smoke
