# Production Webapp Toolkit v2.2.1

Status: v2.2.1 patch release

## Status semantics

v2.2.1 does not change toolkit status semantics. Deterministic checks and explicit evidence remain authoritative; profile detection only selects the existing repository-quality audit path and does not create production truth.

## Trust boundaries

The Python profile scanner remains local and read only. It performs a bounded filesystem walk, does not follow symlinks, excludes common generated, virtual-environment, dependency and test directories, and has no network, subprocess or environment-secret surface.

## Fixes

* Detect standard Python `src/` package layouts instead of requiring a root-level `.py` file.
* Audit Python and shell source files in bounded nested project directories while excluding tests and generated/dependency directories.
* Require shell syntax coverage when project scripts live under directories such as `scripts/`.
* Add regression coverage for `src/` packages, test-only Python files, and nested shell scripts.

## Upgrade notes

v2.2.1 is a backwards-compatible patch release for v2.2.0 adopters. No repository manifest, policy-pack or evidence schema changes are required. Python repositories using a standard `src/` layout can upgrade to obtain correct profile detection and Python-service auditing.

Reference verification:

    bun install --frozen-lockfile
    bun run release:verify
    bun run audit:release . --expected-version 2.2.1
