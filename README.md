# Production Webapp Toolkit

Reusable development standards, CI quality gates, repository auditing and AI-agent guardrails for production web applications.

Initial focus:

- deterministic local verification
- blocking TypeScript checks
- blocking automated tests
- incremental changed-files lint enforcement
- GitHub Actions quality gates
- safe AI/Codex development workflows
- multi-repository consistency auditing
- Playwright E2E foundations

The toolkit is designed to improve existing repositories without requiring large legacy cleanups or exposing production credentials.
